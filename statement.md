# Project Statement

## Problem Statement
Basic calculator applications often provide only arithmetic operations and do not demonstrate modular programming, validation, error handling, or testing in a single small application.

## Scope
The project develops a Python-based command-line calculator supporting basic arithmetic, scientific operations, calculation history, input validation, and automated testing.

## Target Users
- Students
- Beginners learning Python
- Users requiring basic mathematical calculations

## High-Level Features
1. Basic calculator module
2. Scientific calculator module
3. Calculation history
4. Input validation and error handling
5. Automated unit testing
