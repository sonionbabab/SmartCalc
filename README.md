# Python Scientific Calculator

## Overview
Python Scientific Calculator is a modular command-line calculator developed using Python. It provides basic arithmetic, scientific calculations, calculation history, input validation, and automated tests.

## Features
- Basic arithmetic: addition, subtraction, multiplication, division, modulo and power
- Scientific operations: square root, trigonometric functions, logarithms and factorial
- Calculation history
- Input validation and error handling
- Unit tests

## Technologies
- Python 3
- Python `math` module
- Python `unittest`

## Project Structure
- `main.py` - application interface and workflow
- `calculator.py` - basic arithmetic
- `scientific.py` - scientific operations
- `history.py` - calculation history
- `validator.py` - input validation
- `utils.py` - result formatting utility
- `test_calculator.py` - automated tests

## How to Run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run:
   `python main.py`

## How to Test
Run:
`python -m unittest test_calculator.py`

## Target Users
Students and general users who need a simple command-line mathematical calculator.
